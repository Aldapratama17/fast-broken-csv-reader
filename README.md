A single-pass CSV parser that matches csv-reader 1.0.0 byte for byte — columns, rows and every error record ({code, line, row}) included — while running several times faster than the baseline: fast paths for quote-free rows, inlined hot loops, no intermediate allocations. Handles BOM, CRLF, stray CR, quoted fields with "" escapes and junk after closing quotes exactly like csv-reader 1.0.0.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
